## 📚 Topics Covered

### 🔹 Variables

Variables are used to store data values that can be used throughout a program.

```java
int age = 20;
```

---

### 🔹 Data Types

Data types specify the type of value a variable can store.

```java
String name = "Pratima";
double marks = 92.5;
char grade = 'A';
```

---

### 🔹 Methods

Methods are reusable blocks of code that perform a specific task.

```java
public static void greet() {
    System.out.println("Hello, World!");
}
```

---

### 🔹 Classes & Objects

A class is a blueprint for creating objects, while an object is an instance of a class.

```java
Student s = new Student();
```

---

### 🔹 Method Calling

Methods are called to execute the instructions written inside them.

```java
obj.display();
```

---

### 🔹 Pattern Programming

Pattern programs use nested loops to improve logical thinking and coding skills.

```java
for(int i = 1; i <= 5; i++) {
    for(int j = 1; j <= i; j++) {
        System.out.print("* ");
    }
    System.out.println();
}
```
